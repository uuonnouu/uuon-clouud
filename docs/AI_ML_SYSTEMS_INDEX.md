## Smart Pattern Learning

### What It Does
The system learns from how shapes are created and used, then applies that knowledge to improve future results.

**Components:**
- **Cross-Learning Engine** - Shares knowledge between different parts of the system
- **Pattern Recognition** - Identifies common shapes and user preferences
- **Intelligent Caching** - Predicts which shapes you'll need next

**Example Output:**
```javascript
// System learns your preferences
const suggestion = ai.suggest({
  recentShapes: ["torus", "mobius", "kleinBottle"],
  context: "topology"
});

// Returns: { recommended: "trefoilKnot", confidence: 0.87 }
```

## AI Training Tools

### What It Does
Provides clean, structured data that other AI systems can learn from.

**Features:**
- **Neural Export** - AI-readable 3D data format
- **Semantic Tagging** - Labels describing what each shape represents
- **Formula Embedding** - Mathematical equations attached to geometry

**Example Output:**
```javascript
// Export training data for external ML pipeline
const trainingData = ai.exportForTraining({
  shapes: ["sphere", "torus", "cube"],
  includeFormulas: true,
  format: "nerf"
});

// Returns structured dataset ready for ML training
```
