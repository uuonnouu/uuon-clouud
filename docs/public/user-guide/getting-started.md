
# Getting Started with Δmension Mathematical Universe

## Welcome to Mathematical Visualization

Δmension is a professional 3D mathematical visualization platform featuring 1,500+ validated algorithms across multiple domains.

### Quick Start Guide

1. **Select a Shape Category**
   - Browse 25+ categories from the dropdown
   - Each category contains specialized mathematical objects

2. **Adjust Parameters**
   - Use A-M parameter sliders for real-time control
   - Each parameter controls different geometric properties

3. **Export Your Work**
   - GLB/GLTF for 3D applications
   - STL for 3D printing
   - High-resolution images

### Core Features

- **Real-time 3D Rendering** with WebGL optimization
- **26-Parameter Control System** (A-Z parameters)
- **Professional Export Formats** with material data
- **Mobile-Optimized Interface** for all devices

### Support

For questions or support, use the in-app help system or visit our documentation portal.
