# UUON — Origin of the Name

UUON is not an acronym. It is a homophonic respelling of "one" / "won",
using a doubled-U (UU) onset to carry the /w/→/ʌ/ sound: UU-O-N, read
aloud as /wʌn/.

## The devices at work
- Homophonic respelling — spelled to be heard as another word.
  UUON → "one" and "won" (both /wʌn/, a perfect homophone pair).
- Token mirror — UUON reversed is NOUU. The founder handle `uuonnouu`
  is UUON|NOUU, the name reflected around its own center.

## Why it belongs in Clouud
The naming system is itself an instance of the wordplay Clouud's
phonetic layer is built to measure — the same family as the corpus
puns (makes cents/sense, Phil/fill, A.I./a eye) and the same principle
as the W.D.I. notation: the doubled letter is the seam held open, not
decoration.
