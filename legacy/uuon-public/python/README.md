# Python / Quantum Scripts

This directory contains the Python dependency list for the Δmension quantum simulation layer. The quantum features use [Qiskit](https://qiskit.org/) and [Qiskit Aer](https://qiskit.github.io/qiskit-aer/) to run real and simulated quantum circuits.

## What these scripts do

The Node.js backend (via `server/services/qiskitRuntimeService.ts` and `server/services/quantumIntegrationService.ts`) shells out to `python3` to execute quantum circuits at runtime. The three core algorithm scripts are written and saved automatically by the server to the `quantum_scripts/` directory at the project root:

| Script | Algorithm | Purpose |
|---|---|---|
| `quantum_scripts/qaoa.py` | QAOA | Quantum Approximate Optimisation Algorithm — combinatorial optimisation |
| `quantum_scripts/shor.py` | Shor's algorithm | Integer factorisation on quantum hardware |
| `quantum_scripts/grover.py` | Grover's algorithm | Unstructured database search with quadratic speedup |

The scripts are generated by the server on first use; you do not need to create them manually.

## Prerequisites

- Python 3.10 or later (`python3 --version`)
- `pip` package manager

## Installation

Install all required packages from this directory:

```bash
pip install -r python/requirements.txt
```

Or, if you prefer a virtual environment (recommended to avoid version conflicts):

```bash
python3 -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r python/requirements.txt
```

> **Note:** If you use a virtual environment, make sure the environment is active whenever the server is running, so that `python3` on your PATH resolves to the virtualenv interpreter.

## Running a quick check

After installing, verify the environment is set up correctly:

```bash
python3 -c "from qiskit import QuantumCircuit; qc = QuantumCircuit(1); print('Qiskit OK')"
python3 -c "from qiskit_aer import AerSimulator; print('Aer OK')"
```

Both commands should print `OK` with no errors.

## IBM Quantum (optional)

To run circuits on real IBM quantum hardware (instead of the local Aer simulator), set your IBM Quantum API token as an environment variable:

```bash
IBMQ_API_TOKEN=your_token_here
```

The server reads this variable in `server/services/qiskitRuntimeService.ts`. Without a token the service falls back to local simulation automatically.

## Why `requirements.txt` lives here

The file was placed in `python/` (rather than the project root) to prevent Railway and NIXPACKS from auto-detecting the project as a Python application and overriding the Node.js build pipeline.
