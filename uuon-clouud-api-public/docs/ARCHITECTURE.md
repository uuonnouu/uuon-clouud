# UUON Clouud Architecture

Clouud uses a closed-core architecture.

The public layer exposes API access while the reasoning engine remains private.

## Public Layer

- API endpoints
- SDK integrations
- Documentation
- Response verification

## Engine Layer

The private engine manages:

- reasoning orchestration
- provenance generation
- assessment systems
- memory retrieval
- mathematical processing

## Technology Surface

- TypeScript
- Express API
- PostgreSQL persistence
- Structured AI orchestration

Implementation details are not distributed.
