🚀 INSTANT COMMANDS (Copy & Paste)

1. Quick system check (30 seconds):
   bash verify-system.sh

2. Start interactive CLI:
   ./clouud-cli

3. Check status:
   curl http://localhost:5001/api/health | jq '.'

4. List your conversations:
   curl http://localhost:5001/api/conversations | jq '.[] | {id, title}'

5. Create new conversation:
   curl -X POST http://localhost:5001/api/conversations \
     -H "Content-Type: application/json" \
     -d '{"title":"My Project"}'

6. Send message (replace ID with actual ID):
   curl -X POST http://localhost:5001/api/conversations/1/messages \
     -H "Content-Type: application/json" \
     -d '{"content":"What is in my GitHub repos?"}'

🔧 SETUP (Do once)

1. Start Ollama in another terminal:
   ollama serve

2. Configure GitHub:
   cp .env.local.template .env.local
   nano .env.local
   # Add GITHUB_USER and GITHUB_TOKEN

3. Restart Docker:
   docker-compose restart clouud-prod

4. Sync repos:
   curl -X POST http://localhost:5001/api/sync/github/pull-all
