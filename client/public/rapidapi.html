Example: Render a torus

POST to /api/shapes/compute — get back vertices, normals, and UVs

Request

// POST /api/shapes/compute { "shapeType": "torus", "parameters": { "a": 2, "b": 0.5 }, "uSegments": 32, "vSegments": 16 }

Response

{ "vertices": [2.5, 0, 0, ...], "normals": [1, 0, 0, ...], "uvs": [0, 0, ...] }
