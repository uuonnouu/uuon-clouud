  
# ASCII vs. Unicode vs. UTF-7 vs. UTF-8 vs. UTF-32 vs. ANSI  
  
Framed using the **5Ws (Who, What, Where, When, Why)** format — and for each format, painted as a **unique symbolic picture** to help visualize its role and structure. This can be used in educational infographics, immersive code maps, or interactive media.  
  
⸻  
  
🔡** 1. ASCII – The Stone Tablet**  
  
🔹** WHO**  
  
Used by early computer engineers, legacy systems, embedded devices.  
  
🔹** WHAT**  
  
7-bit character encoding (128 characters): A–Z, a–z, 0–9, symbols, control chars.  
  
🔹** WHERE**  
  
In early operating systems, terminals, command-line tools.  
  
🔹** WHEN**  
  
Created in 1960s; still used as a base in modern encodings.  
  
🔹** WHY**  
  
To provide a universal **text foundation** in a tiny format.  
  
🖼️ **Picture**: A **stone slab etched with 128 glyphs**, no colors, no curves — just raw, fixed meaning.  
  
⸻  
  
🌐** 2. Unicode – The Infinite Scroll**  
  
🔹** WHO**  
  
Used by all modern software, databases, browsers, and multilingual platforms.  
  
🔹** WHAT**  
  
Universal character set covering **every writing system** (over 143,000 characters).  
  
🔹** WHERE**  
  
Web, OS-level text rendering, emojis, global scripts.  
  
🔹** WHEN**  
  
Standardized in 1991 — constantly expanding.  
  
🔹** WHY**  
  
To unify text representation across all languages and systems.  
  
🖼️ **Picture**: A **scroll unrolling endlessly**, filled with scripts from every culture, each glowing in its own frequency.  
  
⸻  
  
🔤** 3. UTF-7 – The Messenger Pigeon**  
  
🔹** WHO**  
  
Used in early **email systems** that only accepted **ASCII-safe characters**.  
  
🔹** WHAT**  
  
Encodes Unicode using only **ASCII characters** (e.g., for old SMTP).  
  
🔹** WHERE**  
  
Legacy mail clients and transfer protocols.  
  
🔹** WHEN**  
  
Used briefly in 1990s; largely deprecated now.  
  
🔹** WHY**  
  
To sneak Unicode through **ASCII-only channels**.  
  
🖼️ **Picture**: A tired **pigeon carrying a scroll**, converting its message into squiggles so it passes through narrow pipes.  
  
⸻  
  
⚙️** 4. UTF-8 – The Shape-Shifting Prism**  
  
🔹** WHO**  
  
Dominant web encoding used by developers, APIs, browsers.  
  
🔹** WHAT**  
  
Variable-length encoding: 1 to 4 bytes per character. Backward-compatible with ASCII.  
  
🔹** WHERE**  
  
Websites, databases, mobile apps, APIs — almost everywhere.  
  
🔹** WHEN**  
  
Introduced in 1993, now the **default web standard**.  
  
🔹** WHY**  
  
Efficient, flexible, universal — optimized for **modern internet**.  
  
🖼️ **Picture**: A glowing **prism**, compressing simple text into 1 byte, expanding gracefully for complex scripts.  
  
⸻  
  
🔳** 5. UTF-32 – The Colossus Grid**  
  
🔹** WHO**  
  
Used by data scientists, compilers, Unicode testing suites.  
  
🔹** WHAT**  
  
Fixed-width encoding: **4 bytes per character**.  
  
🔹** WHERE**  
  
In systems where **speed of lookup** is more important than memory size.  
  
🔹** WHEN**  
  
Rarely used in production; mostly in internal processing.  
  
🔹** WHY**  
  
For **absolute predictability** in character indexing.  
  
🖼️ **Picture**: A towering **grid**, each glyph occupying an equal square — massive but precise.  
  
⸻  
  
🪵** 6. ANSI – The Fractured Mirror**  
  
🔹** WHO**  
  
Used by early Windows apps and text editors (Notepad, VB6).  
  
🔹** WHAT**  
  
Extended ASCII (8-bit), but **region-specific** — encoding changes by locale.  
  
🔹** WHERE**  
  
Old Windows systems and legacy databases.  
  
🔹** WHEN**  
  
Popular in the 1980s–1990s.  
  
🔹** WHY**  
  
To support local languages before Unicode existed.  
  
🖼️ **Picture**: A **shattered mirror**, each shard reflecting different language glyphs — incompatible and limited.  
  
⸻  
  
🔹** FINAL SUMMARY (369-style)**  
  
ASCII was the stone — solid, silent, strict. Unicode is the scroll — infinite, evolving, shared. UTF-8 is the prism — compact yet expansive. UTF-32 is the grid — heavy but exact. ANSI is the fractured mirror — localized, legacy. UTF-7 was the pigeon — a clever trick from a bygone era. Together, they form the history of **human language encoded into machine breath**.
