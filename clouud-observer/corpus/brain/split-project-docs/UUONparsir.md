# UUONparsir  
# Advanced algorithm visualization platform. See ++[USER_GUIDE.md](https://replit.com/@philruiziii/ParaGraphkh#USER_GUIDE.md)++ for detailed usage instructions.  
## Deployment  
1. Environment Setup:  
    * Set required environment variables in Replit Secrets  
    * Configure database credentials  
    * Set API keys and security tokens  
2. Installation: pip install -r requirements.txt    
3. Database Setup:  
    * Tables auto-create on first run  
    * Initial data seeding handled by database_handler.py  
4. Running Tests: python run_tests.py    
5. Starting the Application: streamlit run AppFeal.py
