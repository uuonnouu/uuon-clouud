**EXTRUSION MATH (Push Up):**  
  
```  
2D Circle: x² + y² = r²  
3D Cylinder: x² + y² = r², 0 ≤ z ≤ h  
  
2D Square: |x| ≤ a, |y| ≤ a    
3D Cube: |x| ≤ a, |y| ≤ a, |z| ≤ a  
  
2D Triangle: vertices (x₁,y₁), (x₂,y₂), (x₃,y₃)  
3D Prism: same vertices + z-coordinate: (x₁,y₁,z), (x₂,y₂,z), (x₃,y₃,z)  
```  
  
**REVOLUTION MATH (Spin Around):**  
  
```  
2D Circle at (r,0): x² + y² = r²  
3D Sphere: x² + y² + z² = R²  
  
2D Line: y = mx (triangle edge)  
3D Cone: x² + y² = (mz)²  
  
2D Rectangle: rotate around edge  
3D Cylinder: x² + y² = r², 0 ≤ z ≤ h  
```  
  
**THE Z-TRANSFORMATION:**  
  
```  
2D point: (x, y)  
ADD Z: (x, y, z)  
  
2D equation: f(x,y) = 0  
3D equation: f(x,y,z) = 0  
```
