ONE-TIME SETUP (10 minutes total)

1. Download Ollama
   Visit: https://ollama.ai
   Click: Download for macOS
   Install normally (like any Mac app)

2. Start Ollama
   Open Terminal, type:
   
       ollama serve
   
   Leave this running. Don't close.

3. Pull the model (in a new terminal)
   
       ollama pull mistral
   
   Wait for "success" message.

4. Start CLOUUD (same new terminal)
   
       cd ~/uuon-c1ouud && ./launch-clouud
   
   You see the menu. Done.

NEXT (OPTIONAL)

Want to sync your GitHub repos to search locally?

1. Edit .env.local:
   cd ~/uuon-c1ouud
   cp .env.local.template .env.local
   nano .env.local
   
   Add:
   GITHUB_USER=your_username
   GITHUB_TOKEN=your_token (from github.com/settings/tokens)

2. Restart Docker:
   docker-compose restart clouud-prod

3. Sync repos:
   curl -X POST http://localhost:5001/api/sync/github/pull-all
