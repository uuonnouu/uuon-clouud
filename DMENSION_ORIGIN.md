# Δmension — Origin of the Name

Δmension is "dimension" with the *i* elided and Δ (delta) set in its
place. Read aloud it is still "dimension"; spelled, it foregrounds Δ —
the difference/change operator and the triangle.

## The device
- Respelling by elision + symbol substitution: dimension → Δmension.
  The dropped *i* is the seam; Δ marks it, the same way UUON's doubled
  U marks the /w/ onset.
- Δ is load-bearing, not decorative: delta = difference operator, and
  the triangle — consistent with the triangle-dominance and Robertson
  pyramid geometry the platform is built on.
