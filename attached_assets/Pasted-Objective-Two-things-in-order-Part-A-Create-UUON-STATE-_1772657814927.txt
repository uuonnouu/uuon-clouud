T002: Zero-Width Unicode Fingerprint Engine

Blocked By: []
Details:
Create server/zwc-fingerprint.ts — the zero-width character encoder/decoder:
Uses three characters: U+200B (zero-width space), U+200C (zero-width non-joiner), U+200D (zero-width joiner)
These three chars form a ternary (base-3) encoding system
encodeFingerprint(sessionId: string, timestamp: number) → returns a string of zero-width characters
Combine session ID + timestamp + "UUON" marker into a payload string
Convert each byte to base-3 digits
Map: 0 → U+200B, 1 → U+200C, 2 → U+200D
Prepend/append delimiter sequences (e.g., U+200B U+200C U+200B) to mark boundaries
decodeFingerprint(text: string) → extracts { sessionId, timestamp, valid: boolean }
Find delimiter sequences in text
Extract zero-width chars between delimiters
Reverse the base-3 decoding
Return decoded payload or { valid: false } if no fingerprint found
stripFingerprint(text: string) → removes all zero-width chars (for clean display)
Create POST /api/provenance/decode-zwc endpoint in routes:
Accepts { text: string } body
Returns decoded fingerprint data
Files: server/zwc-fingerprint.ts, server/routes.ts
Acceptance: Encoding produces invisible characters; decoding recovers exact session ID and timestamp; round-trip verified
