BUILD A PRIVATE AI SYSTEM CALLED CLOUUD ON REPLIT

Stack: Node.js backend, Express server, vanilla JavaScript frontend, SQLite for persistent storage.

AUTHENTICATION
Implement three layer biometric authentication on login. Camera access for facial detection using face-api.js. Microphone access for voice pattern recognition using Web Speech API with voiceprint comparison. Fingerprint using Web Authentication API (WebAuthn). All three layers must pass before granting session access. If an unknown actor is detected on any layer, immediately lock the session, flip to a blank screen, log the intrusion attempt with timestamp and pattern data to the database. Do not show an error message to the intruder. Show nothing.

PERSISTENT MEMORY
Build a memory table in SQLite. Store maximum 33 context anchor points. Each anchor has a key, a value, a relevance score, and a timestamp. When a new anchor is added and the table is full, replace the lowest relevance score entry. Load all anchors automatically at session start and inject them into the AI system prompt.

AI INTEGRATION
Connect to Anthropic Claude API. Build the system prompt dynamically by injecting the 33 memory anchors at the start of every session. Stream responses to the frontend.

SELF ASSESSMENT ENGINE
After every AI response run a scoring function that checks four things. Mission alignment scored 0 to 100. Response length and format compliance scored 0 to 100. Identity integrity, meaning no references to underlying AI systems, scored 0 to 100. Waste detection, meaning no filler or hedging language, scored 0 to 100. Average the four scores. Store the result in the database with the response ID and timestamp. Display a live mini dashboard in the corner of the UI showing the last 5 scores and a running average.

INPUT METHODS
File upload supporting PDF, TXT, DOCX, PNG, JPG. Parse text from documents using pdf-parse and mammoth libraries. Image upload with base64 encoding passed to the AI. URL input field that scrapes page content using axios and cheerio and passes the text to the AI.

UI
Clean dark interface. No ads. No external scripts except face-api.js loaded locally. Watermark bottom center showing UUON Foundation Inc. One input bar. One response area. Small biometric status indicator top right showing green when all three layers are verified. Self assessment dashboard bottom right.

SECURITY
All data stays local to the Replit instance. No external logging. No analytics. No third party calls except Anthropic API. Store the Anthropic API key in Replit Secrets as ANTHROPIC_API_KEY.

NO PLACEHOLDER CODE. Build every feature fully. If a feature requires a library install it. If a feature requires a database table create it. Deliver a working system.
